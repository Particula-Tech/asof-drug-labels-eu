# 2. QUALITATIVE AND QUANTITATIVE COMPOSITION

One ml contains 10 mg ranibizumab*.
Each vial contains 2.3 mg of ranibizumab in 0.23 ml solution.
This provides a usable amount to deliver a single dose of 0.05 ml containing 0.5 mg ranibizumab to adult patients and a single dose of 0.02 ml containing 0.2 mg ranibizumab to preterm infants.

*Ranibizumab is a humanised monoclonal antibody fragment produced in Escherichia coli cells by recombinant DNA technology.

For the full list of excipients, see section 6.1.

[Lucentis 10 mg/ml solution for injection in pre-filled syringe]

One pre-filled syringe contains 0.165 ml, equivalent to 1.65 mg ranibizumab.
The extractable volume of one pre-filled syringe is 0.1 ml.
This provides a usable amount to deliver a single dose of 0.05 ml containing 0.5 mg ranibizumab.
