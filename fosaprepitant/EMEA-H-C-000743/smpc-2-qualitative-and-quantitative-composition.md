# 2. QUALITATIVE AND QUANTITATIVE COMPOSITION

Each vial contains fosaprepitant dimeglumine equivalent to 150 mg fosaprepitant, which corresponds to 130.5 mg of aprepitant.
After reconstitution and dilution 1 ml of solution contains 1 mg fosaprepitant (1 mg/ml) (see section 6.6).

For the full list of excipients, see section 6.1.
