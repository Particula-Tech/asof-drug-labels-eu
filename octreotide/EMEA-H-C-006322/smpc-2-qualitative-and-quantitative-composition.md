# 2. QUALITATIVE AND QUANTITATIVE COMPOSITION

Each pre-filled pen of 1 mL contains octreotide hydrochloride equivalent to 20 mg octreotide.

Excipients with known effect

Oczyesa contains 63 mg of alcohol (ethanol) in each dose unit, which is equivalent to 63 mg/1 mL (6.5% w/w), and 408 mg soybean phosphatidylcholine.

For the full list of excipients, see section 6.1.
