# 6.6 Special precautions for disposal and other handling

Before use, Neulasta solution should be inspected visually for particulate matter.
Only a solution that is clear and colourless should be injected.

The on-body injector must only be used with the Neulasta pre-filled syringe co-packed in the carton.
The Neulasta pre-filled syringe for manual administration must not be used with the on-body injector.

Excessive shaking may aggregate pegfilgrastim, rendering it biologically inactive.

When administering using the manual pre-filled syringe, allow the pre-filled syringe to reach room temperature before injecting.

Any unused product or waste material should be disposed of in accordance with local requirements.
