# 2. QUALITATIVE AND QUANTITATIVE COMPOSITION

Each film-coated tablet contains 2.5 mg apixaban.

Excipient(s) with known effect

Each 2.5 mg film-coated tablet contains 51 mg lactose (see section 4.4).

For the full list of excipients, see section 6.1.

[Eliquis 5 mg film-coated tablets]

Each film-coated tablet contains 5 mg apixaban.

Excipients with known effect

Each 5 mg film-coated tablet contains 103 mg lactose (see section 4.4).

[Eliquis 0.15 mg granules in capsules for opening]

Each capsule contains 0.15 mg apixaban

Each capsule of 0.15 mg contains up to 124 mg of sucrose.

[Eliquis 0.5 mg coated granule in sachet]

Eliquis 0.5 mg coated granule in sachet
Each sachet contains one 0.5 mg apixaban coated granule.

Excipient with known effect
Each sachet contains 10 mg lactose (see section 4.4).

Eliquis 1.5 mg coated granules in sachet
Each sachet contains three 0.5 mg (1.5 mg) apixaban coated granules.

Each sachet contains 30 mg lactose (see section 4.4).

Eliquis 2.0 mg coated granules in sachet
Each sachet contains four 0.5 mg (2 mg) apixaban coated granules.

Each sachet contains 40 mg lactose (see section 4.4).
