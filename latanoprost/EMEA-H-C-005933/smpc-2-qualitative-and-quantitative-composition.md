# 2. QUALITATIVE AND QUANTITATIVE COMPOSITION

1 mL eye drops emulsion contains 50 micrograms of latanoprost.
A single-dose container of 0.3 mL eye drops emulsion contains 15 micrograms of latanoprost.
One drop contains approximately 1.65 micrograms latanoprost.

Excipient with known effect:

One ml of emulsion contains 0.05 mg cetalkonium chloride (see section 4.4)

For the full list of excipients, see section 6.1.
