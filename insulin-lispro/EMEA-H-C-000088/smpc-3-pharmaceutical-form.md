# 3. PHARMACEUTICAL FORM

A solution for injection, in a 1.5 mL cartridge (100 U/mL of insulin lispro) to be used in conjunction with the B-D Pen Cartridge System, B-D Pen+ (B-D Pen Ultra), Lilly-Diapen I, Lilly-Diapen II or Autopen pen injection delivery systems for parenteral subcutaneous administration.
