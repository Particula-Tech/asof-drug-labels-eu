# 3. PHARMACEUTICAL FORM

Humalog is a sterile, clear, colourless, aqueous solution of insulin lispro ([Lys (B28), Pro (B29)] human insulin analog, rDNA origin ) adjusted to pH 7.0 - 7.8.
A solution for injection, in a 10 ml vial to be used in conjunction with an appropriate syringe (40 U markings).

[Humalog vials (100 U/ml, solution for injection)]

A solution for injection, in a 10 ml vial to be used in conjunction with an appropriate syringe (100 U markings).

[Humalog cartridge (100 U/ml, solution for injection)]

A solution for injection, in a 1.5 ml cartridge.
To be used with a CE marked pen as recommended in the information provided by the device manufacturer.

[Humalog cartridge (100 U/ml, solution for injection) (SmPC 4)]

A solution for injection, in a 3 ml cartridge.
