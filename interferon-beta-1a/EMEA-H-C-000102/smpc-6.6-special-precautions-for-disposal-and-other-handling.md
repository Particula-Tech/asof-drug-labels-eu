# 6.6 Instructions for use and handling

AVONEX is provided as ready to use solution for injection in a pre-filled syringe.

AVONEX should be removed from the refrigerator to allow to warm to room temperature
(15-30�C) for approximately 30 minutes before injection.
Do not use external heat sources such as hot water to warm AVONEX 30 µg solution for injection.

The solution for injection should be inspected and if it contains particulate matter or is other than clear colourless, the pre-filled syringe should not be used.
The injection needle for IM injection is provided.
The formulation does not contain a preservative.
Each pre-filled syringe of AVONEX contains a single dose only.
The unused portion of any pre-filled syringe should be discarded.
