# 6.4 Special precautions for storage

Store in a refrigerator (2°C - 8°C).

DO NOT FREEZE.

AVONEX can be stored at room temperature (between 15°C and 30°C) for up to one week.

Store in the original package (sealed plastic tray) in order to protect from light (see section 6.5).

[AVONEX 30 micrograms/0.5ml solution for injection in pre-filled pen.]

The AVONEX PEN contains a pre-filled syringe of AVONEX and must be stored in the refrigerator.

Should refrigeration be unavailable, AVONEX PEN can be stored at room temperature (between 15°C and 30°C) for up to one week.

Store the AVONEX PEN in the inner carton in order to protect from light (see section 6.5).
