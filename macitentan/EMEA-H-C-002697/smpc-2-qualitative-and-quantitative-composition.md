# 2. QUALITATIVE AND QUANTITATIVE COMPOSITION

Each film-coated tablet contains 10 mg macitentan.

Excipients with known effect

Each film-coated tablet contains approximately 37 mg of lactose (as monohydrate) and approximately 0.06 mg of soya bean lecithin (E322).

For the full list of excipients, see section 6.1.

[Opsumit 2.5 mg dispersible tablets]

Each dispersible tablet contains 2.5 mg macitentan.

Each dispersible tablet contains approximately 25 mg of isomalt.
