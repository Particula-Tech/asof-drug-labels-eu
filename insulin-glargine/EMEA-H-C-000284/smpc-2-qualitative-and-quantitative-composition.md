# 2. QUALITATIVE AND QUANTITATIVE COMPOSITION

Each ml of the solution for injection contains 3.64 mg of the active substance insulin glargine, corresponding to 100 IU human insulin.
Each pen contains 3 ml, equivalent to 300 IU.

Insulin glargine is an insulin analogue produced by recombinant DNA technology using Escherichia coli (K 12 strains).

For excipients, see section 6.1.
