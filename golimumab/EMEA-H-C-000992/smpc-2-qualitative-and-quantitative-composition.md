# 2. QUALITATIVE AND QUANTITATIVE COMPOSITION

One 0.5 mL pre-filled pen contains 50 mg of golimumab*.

* Human IgG1κ monoclonal antibody produced by a murine hybridoma cell line with recombinant DNA technology.

Excipient with known effect:
Each pre-filled pen contains 20.5 mg sorbitol per 50 mg dose.

For the full list of excipients, see section 6.1.

[Simponi 50 mg solution for injection in pre-filled syringe.]

One 0.5 mL pre-filled syringe contains 50 mg of golimumab*.

Each pre-filled syringe contains 20.5 mg sorbitol per 50 mg dose.

[Simponi 100 mg solution for injection in pre-filled pen.]

Each 1 mL pre-filled pen contains 100 mg of golimumab*.

Each pre-filled pen contains 41 mg sorbitol per 100 mg dose.

[Simponi 100 mg solution for injection in pre-filled syringe.]

Each 1 mL pre-filled syringe contains 100 mg of golimumab*.

Each pre-filled syringe contains 41 mg sorbitol per 100 mg dose.
