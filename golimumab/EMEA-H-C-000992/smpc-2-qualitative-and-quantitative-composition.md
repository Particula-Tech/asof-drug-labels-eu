# 2. QUALITATIVE AND QUANTITATIVE COMPOSITION

One pre-filled pen contains 45 mg golimumab* in 0.45 mL.
1 mL solution contains 100 mg golimumab.

Each pre-filled pen can deliver 0.1 mL to 0.45 mL (corresponding to 10 mg to 45 mg golimumab) in increments of 0.05 mL.

* Human IgG1κ monoclonal antibody produced by a murine hybridoma cell line with recombinant DNA technology.

Excipients with known effect
Each pre-filled pen contains 18.5 mg sorbitol (E420) per 45 mg dose.

Each pre-filled pen contains 0.068 mg of polysorbate 80 (E433) per 45 mg dose.

For the full list of excipients, see section 6.1.
