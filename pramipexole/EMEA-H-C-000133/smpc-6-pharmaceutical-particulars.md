# 6. PHARMACEUTICAL PARTICULARS

The appearance of SIFROL tablets is the following:

| Strength(mg base/mg salt) | Appearance |
| --- | --- |
| 0.088/0.125 | flat, round, 6 mm diameter, no score |
| 0.18/0.25 | flat, oval, 7.86 x 5.63 mm, scores on both sides |
| 0.7/1.0 | flat, round, 9 mm diameter, scores on both sides |
| 0.88/1.25 | flat, oval, 11.81 x 8.46 mm, scores on both sides |
| 1.1/1.5 | flat, round, 11 mm diameter, scores on both sides |

All tablets are white and have a code embossed.
